### Proposed change (all inside `cmd_board` in `tools/otr.py`)

1. **Enumerate branches robustly.** Replace
   `git("branch", "--list", "issue-*/*")` with
   `git("for-each-ref", "--format=%(refname:short)", "refs/heads/issue-*")`.
   The current call returns lines such as `* issue-3/7f21e5e7` for a branch
   checked out in a worktree; `.strip()` leaves the `* `/`+ ` marker, so
   `startswith(f"issue-{n}/")` fails and the branch vanishes from the board
   (Evidence 1). Every subagent branch lives in a worktree, so this affects
   exactly the branches the issue is about.

2. **Decide "not yet merged".** A branch is unmerged when its record is not
   on main (existing `on_main` check) and additionally `git merge-base --is-ancestor BRANCH main` is false (a merged branch whose worktree is
   still present would otherwise be re-listed; `otr accept` deletes the
   branch so this is a belt-and-braces check, cheap and exact). Branches
   already merged keep the current `landed` line.

3. **Read the record from the branch tip without checkout.**
   `git("show", BRANCH + ":docs/issue-N/reports/HEX.md", check=False)`.
   `git show` exits 128 and prints nothing to stdout when the path is absent
   (Evidence 2); the empty string maps to `no record`. Otherwise
   `frontmatter_of(text)` yields `type` and `loop_state` (default `?` as the
   merged loop already does). Parse with the same `parse_frontmatter` the
   linter uses, so branch and main records are read identically.

4. **Render.** For each unmerged branch print one line:
   `    branch issue-N/HEX: TYPE LOOP_STATE[, approved]`
   or `    branch issue-N/HEX: no record[, approved]`.
   `approved` is appended when HEX is in `issues[n]["approved"]`, which is
   already collected from `docs/issue-N/approvals/HEX.md` on main. This
   replaces the current `in flight` / `approved, awaiting delivery` tags; the
   `landed` tag for merged branches is retained verbatim. The merged-record
   lines (`    HEX  TYPE LOOP_STATE`) are not touched.

5. **Branch for an issue that has no `issue.md` on main** (e.g. the issue
   commit not yet on main): skip silently as today, because `issues` is keyed
   from main; noted under Deviations as a judgment call, not changed.

Expected diff size: roughly 15 lines in `cmd_board`; no new functions, no
changes to `record_lint.py`, templates, or approve/accept/reject.
